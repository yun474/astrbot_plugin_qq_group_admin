## ✨ 群管功能

| 功能 | 内容 |
| --- | --- |
| 🔇 成员管理 | 禁言、解禁、踢人和禁言状态查询，支持多人操作 |
| 📨 入群审批 | Markdown 申请卡片、按钮审批、引用通知回复审批 |
| 🔎 关键词管理 | 入群回答白黑词审批，群消息违禁词禁言、撤回和踢人 |
| 🧩 进群验证 | 算术题和自定义问题，答错或超时可禁言、移出群聊 |
| 👋 成员通知 | 自定义欢迎与退群文案，支持艾特和头像 |
| 🗝️ 分群管理 | 插件群管、功能开关、词表与验证设置可按群配置 |
| 🤖 LLM 工具 | 禁言、解禁、踢人、状态查询、申请列表与审批 |

<a id="usage"></a>

## 🚀 安装与使用

最低要求 **AstrBot 4.26.5**，并使用配套 WebUI。当前测试版本为 **AstrBot 4.29.3**。

在 AstrBot 插件管理中使用仓库链接安装，或导入插件 ZIP。手动安装时，将插件目录放入 `data/plugins/`，安装 `requirements.txt` 中的依赖后重载。[插件仓库](https://github.com/yun474/astrbot_plugin_qq_group_admin)

使用前完成以下配置。

1. 选择 `qq_official` 或 `qq_official_webhook` 适配器，启用群/C2C 事件。
2. 将机器人设为目标群的管理员，并开通需要使用的群管理接口。
3. 使用 Markdown 卡片和按钮时，开通对应权限。Webhook 订阅 `INTERACTION_CREATE`。
4. 使用进群验证或全群关键词处理时，开通全量群消息接收能力。

**在群里 @机器人后，发送指令正文。** 也可使用 AstrBot 当前会话配置的唤醒词，例如 `!群管帮助`。使用 `/` 前缀时，在 AstrBot 中将 `/` 配置为唤醒词。

| 指令 | 用途 |
| --- | --- |
| `禁言 @用户 [时间]` | 禁言一个或多个成员，默认 1 分钟 |
| `解禁 @用户` | 解除成员禁言 |
| `禁言状态` | 查看全员禁言规则及被禁言成员 |
| `踢出 @用户` / `踢人 @用户` | 移出一个或多个成员，每次最多 10 人 |
| `添加群管 @用户` / `删除群管 @用户` | 管理本群插件群管 |
| `群管列表` / `群管帮助` | 查看名单与帮助 |
| `群管功能` | 打开分类菜单，查看和调整当前配置 |
| `验证列表` | 查看本群待验证成员 |
| `验证放行 @用户` | 放行成员，解除验证失败产生的禁言 |
| `重新验证 @用户` | 为成员重新出题并清零答错次数 |

时间支持 `30秒`、`10分`、`2小时`、`1天2小时`，纯数字按分钟。`0`、`解除`、`解禁`表示解除禁言。禁言适用于普通成员，全员禁言规则支持查询。

### 群管功能菜单

首页提供七个分类，分类导航、状态和修改入口统一使用蓝字指令。

| 分类 | 内容 |
| --- | --- |
| 成员管理 | 禁言、解禁、踢人、禁言状态 |
| 入群审批 | 申请通知、人工审批、白黑词与匹配设置 |
| 进群验证 | 验证题型、次数、限时和处理方式 |
| 发言管理 | 违禁词禁言、撤回、踢人及结果通知 |
| 通知设置 | 成员进群与退群通知 |
| LLM 工具 | 各项工具开关和调用权限 |
| 群信息与权限 | 群 UMO、插件群管名单、增删入口和踢人授权 |

## 👢 踢出群成员

发送 `踢出 @成员` 或 `踢人 @成员`，可同时艾特最多 10 人。机器人需要在群主侧与机器人 WEB 管理端分别开启「移除群成员」权限。

「群信息与权限」和 WebUI 提供两个独立的踢人授权开关。

| 设置 | 默认值 |
| --- | --- |
| 群主/管理员可踢人 | 开启 |
| 插件群管可踢人 | 关闭 |

AstrBot 管理员拥有踢人权限。两项授权适用于人工指令和 LLM 踢人工具，支持全局与分群配置。

### 自动踢人与禁言

进群验证可以分别设置答错和超时后的移出处理。关键词踢人使用独立踢人词表。验证或关键词踢人失败后，会按对应功能的禁言时长回退禁言。

| 场景 | 回退禁言时长 |
| --- | --- |
| 进群验证答错或超时 | 验证失败禁言时长，默认 1 天 |
| 关键词踢人 | 违禁词禁言时长，默认 10 分钟 |

<a id="review"></a>

## 📨 入群申请审批

入群申请以 Markdown 卡片展示昵称、时间、来源和验证内容。人工审批支持按钮和引用回复两种方式。

### 按钮审批

| 按钮 | 可操作成员 |
| --- | --- |
| 群管同意 / 群管拒绝 | QQ 原生群主和群管理员 |
| 授权同意 / 授权拒绝 | AstrBot 管理员和本群插件群管 |

点击后直接处理申请。审批结果消息会艾特点击按钮的处理人。

### 引用回复审批

引用机器人发出的申请通知，回复 `同意`、`通过`、`拒绝`，或 `拒绝 理由`。

例如 `拒绝 未完成入群验证`。引用审批支持当前会话配置的 AstrBot 唤醒词，也兼容 `/同意`、`/拒绝 理由`。

## 🔎 关键词管理

在 WebUI「全局与分群配置」的「关键词管理」中设置，也可使用群内菜单。各项关键词功能默认关闭。

### 入群白词与黑词

开启「入群关键词审批」后，根据入群问题的回答匹配白黑词。

- 命中白词时自动同意，命中黑词时自动拒绝。
- 同时命中时按优先规则处理，默认黑词优先。
- 其余申请继续人工审批。

默认使用普通文本包含匹配，忽略大小写。进群白黑词支持切换为正则匹配，例如 `^(天文|摄影)爱好者$`。

### 消息违禁词与踢人词

消息违禁词用于禁言和撤回，两项开关可分别配置。禁言时长默认 10 分钟。撤回需要机器人具备群管理员身份，适用于普通成员 2 分钟内的消息。

踢人词表独立配置。命中后移出发言者，移出失败时按违禁词禁言时长处理。结果通知由「关键词踢人通知」单独控制。开启撤回时，命中的踢人词消息也会尝试撤回。

进群白词、进群黑词、违禁词和踢人词均支持查看、添加、删除和清空。

<a id="verify"></a>

## 🧩 进群验证

在 WebUI「进群验证」中开启，或发送 `群管功能 进群验证 开启`。新成员入群后收到一道验证题，已有成员可通过「重新验证」补做验证。

| 题型 | 作答方式 |
| --- | --- |
| 算术题 | 随机加减乘除，点击四个选项按钮作答 |
| 自定义问题 | 配置 `问题 => 正则`，成员在群里直接发送答案 |

自定义问题示例为 `本群主题是什么？ => ^(天文\|astronomy)$`。题目、答错次数、限时和处理方式均可配置。

| 设置 | 默认值 |
| --- | --- |
| 允许答错次数 | 3 次 |
| 验证限时 | 10 分钟，填 0 表示不限时 |
| 答错处理 | 禁言 |
| 验证失败禁言时长 | 1 天 |
| 超时处理 | 按失败禁言 |

答错达到上限时可选择禁言或移出。超时处理支持不处理、提醒一次、按失败禁言和移出群聊。选择移出时，失败会回退到验证失败禁言时长。

验证完成前的发言会被撤回并提醒。验证限时从题目成功发出后开始。算术题按钮需要 Markdown 和按钮权限，验证题的主动发送使用 QQ 群主动消息额度。

群管可通过「验证列表」「验证放行」「重新验证」管理验证。当前验证设置包含移出操作时，重新验证需要踢人权限。

<a id="permissions"></a>

## 🗝️ 权限与分群配置

| 操作 | AstrBot 管理员 | 插件群管 | QQ 群主/管理员 | 普通成员 |
| --- | :---: | :---: | :---: | :---: |
| 禁言、解禁、状态查询、人工审批 | ✅ | ✅ | ✅ | — |
| 踢人指令与踢人工具 | ✅ | 可配置，默认关闭 | 可配置，默认开启 | — |
| 修改踢人授权 | ✅ | — | 分群模式可修改 | — |
| 添加/删除插件群管 | ✅ | — | 可配置，默认关闭 | — |
| 查看/修改本群功能 | ✅ | 分群模式可修改 | 分群模式可修改 | — |
| 修改全局配置 | ✅ | — | — | — |
| 查看群管名单与帮助 | ✅ | ✅ | ✅ | ✅ |

在 WebUI「全局与分群配置」中选择配置方式。

- 关闭分群时，各群使用全局配置。
- 开启分群后，按群 UMO 配置权限、指令、通知、词表、验证和工具。
- 群内首次修改会自动建立该群条目，后续修改同步保存到 WebUI。
- 群 UMO 使用 `平台ID:GroupMessage:真实群ID`，可在「群信息与权限」中查看。
- 编辑 WebUI 前重新打开配置页，即可读取群内修改后的最新内容。

旧配置会迁入新面板。显示为待确认的群条目，可在目标群查询 UMO 后填写，并开启「已确认 UMO 属于目标群」。

### LLM 工具

禁言、解禁、禁言状态、申请列表与审批工具支持「严格审查唤醒人权限」。关闭时由模型决定调用，开启后由群管使用。

踢人工具 `qq_group_kick_member` 默认关闭，使用群主/管理员与插件群管两项踢人授权。工具处理后会发送详细结果通知。

<a id="notices"></a>

## 👋 进退群通知

欢迎和退群通知分别提供开关与模板。

| 占位符 | 进群通知 | 退群通知 |
| --- | --- | --- |
| `{member_at}` | 艾特新成员 | 成员 OpenID |
| `{member_avatar}` | 成员头像 | 成员头像 |

欢迎文案可写为 `欢迎 {member_at} 加入群聊！`。退群文案可搭配 `{member_avatar}` 和 `有成员退出了群聊。`。插件踢人的同次退群事件由踢人结果统一提醒。

## 💾 数据与备份

插件数据位于 `data/plugin_data/astrbot_plugin_qq_group_admin/`，功能配置保存在 AstrBot 的插件配置文件中。备份时同时保存插件数据目录和配置文件。
